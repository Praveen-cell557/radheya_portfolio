## 🧭 About

This repo holds the source for **Praveen Rathod's** portfolio — showcasing skills, tools, projects, verified security findings, TryHackMe rank, certifications, and achievements in digital forensics, pentesting, and OSINT.

Everything lives in a single `index.html` — no dependencies to install, no build pipeline.

---

## ✨ Features

- 🖥️ **One-file site** — markup, styles, and logic all in `index.html`
- 📱 **Fully responsive** — mobile, tablet, desktop
- 🧩 **Data-driven sections** — skills, tools, certs & terminal text render from small JS arrays
- 🎯 **Filterable certifications grid**
- 🗂️ **Swipeable project carousel**
- 🧵 **Minimal animation** — subtle scroll fade-ins only, no flashy motion
- 🖼️ **Click-to-preview photo slots**
- 🚫 **Zero dependencies**

## 🧱 Tech Stack

| Layer | Technology |
|---|---|
| Markup | HTML5 |

| Fonts | Google Fonts — Space Grotesk, JetBrains Mono |

---

## 🚀 Running It

No installation needed.

```bash
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

Or serve it locally:

```bash
python3 -m http.server 8000
```

---

## 🎨 Customizing Content

| To change... | Edit... |
|---|---|
| Photos | `IMAGES` object in `<script>`, or click the upload slots on the page |
| Skill ratings | the `SK` array |
| Tools | the `TL` array |
| Certifications | the `CE` array |
| Terminal text | the `L` array |
| Contact details | the `#contact` section |
